# Inwood at Great Notch Website

Modern static website for the Inwood at Great Notch home community in Little Falls, New Jersey.

## Pages

- `index.html` - Home page with community overview, amenities, shareholder links, CP Management portal link, and Google Maps embed.
- `gallery.html` - Gallery of pictures of Inwood using approved photos from the existing community website.

## Features

- Charcoal and botanical-green design with a persistent light/dark toggle.
- Responsive layout for desktop and mobile.
- CP Management resident portal link for tickets and home, apartment, or complex-related requests.
- Homeowner shareholder links with lock icons.
- Google Maps embed for 181 Long Hill Road, Little Falls, NJ 07424.
- Filterable gallery with an accessible image lightbox, previous/next controls, and keyboard navigation.

## Assets

Gallery images are stored in `assets/gallery/` and reused with permission. Lucide icons are bundled locally in `assets/lucide.min.js` (ISC license). DM Sans and Manrope fonts are loaded from Google Fonts, with system fallbacks. Screenshots used for visual verification are ignored by git through `.gitignore`.
